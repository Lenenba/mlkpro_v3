## Rôle de chaque format

| Format | Fonction | Appel à l'action principal |
| --- | --- | --- |
| `F00` | Humaniser la marque | Découvrir l'onboarding |

## Formule à employer dans une démo métier

À l'oral :

> Je passe rapidement sur la création du client : le tutoriel `G03` montre chaque champ. Ici, regardons plutôt comment sa réservation arrive dans la journée du salon.

À l'écran :

```text
Besoin du pas-à-pas ?
G03 — Créer un client
Lien dans la description
```

Cette formule suffit. Ne pas interrompre le récit métier par une seconde démonstration complète.

```text
00:00 Le problème d'une journée fragmentée

07:00 Accueil et file hybride

12:00 Fidéliser — voir G06

```

Les minutages sont ajustés après le montage final.

## Miniatures

- Une seule promesse, quatre à six mots maximum.
- Une capture d'interface nette et un visage uniquement quand il apporte de la confiance.
- Même famille de couleurs et même emplacement du logo.
- Identifiant de série discret dans un coin.
- Vérifier la lisibilité à environ 320 px de largeur.

## Suivi

Après publication, renseigner `publication_url` dans `series-catalog.csv`. Les anciennes URL restent dans l'historique de publication si une vidéo est remplacée ; ne pas casser silencieusement les liens déjà placés dans les démos métier.
